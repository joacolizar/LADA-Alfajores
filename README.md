LADA Alfajores es una página web desarrollada para simular una tienda online de alfajores. El proyecto presenta los productos disponibles, permite visualizar un carrito de compras y cuenta con una sección de contacto. 
El objetivo principal es aplicar los conocimientos adquiridos durante la cursada en el desarrollo de una página web utilizando HTML y CSS, manteniendo una estructura clara, organizada y adaptable.

SECCIONES
Inicio: presentación de la tienda y muestra de los productos.
Carrito: sección destinada a los productos seleccionados para la compra.
Contacto: formulario para enviar consultas, reclamos o mensajes.
Tecnologías utilizadas
HTML5
CSS3
Google Fonts
